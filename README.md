# centre-horizon-carrousel

Petite application web qui affiche un diaporama de photos sous forme de carrousel (HTML, CSS, JavaScript).

## Fonctionnalités

- Affichage d'une photo avec son titre
- Barre d'outils masquée au départ, affichée/cachée avec le bouton « Afficher/Cacher »
- Photo précédente / suivante, **en boucle** (la dernière ramène à la première et inversement)
- Photo aléatoire (jamais deux fois la même de suite)
- Défilement automatique toutes les 3 secondes (bouton lecture/pause, un seul minuteur actif)
- Navigation au clavier avec les flèches gauche et droite
- Compteur de photos
- Affichage adapté aux petits écrans (responsive)

## Technologies

- HTML5, CSS3, JavaScript
- [Font Awesome](https://fontawesome.com/) pour les icônes
- [Google Fonts](https://fonts.google.com/) : police Open Sans
